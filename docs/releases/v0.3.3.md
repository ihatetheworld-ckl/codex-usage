# Codex Usage v0.3.3

修复 macOS 的几类误隐藏路径，并改善仅安装 Windows 桌面版时的用量连接。

- macOS 不再把每个前置辅助窗口都当成模态弹窗；支持可见主窗口切换和旧主窗口在其他空间／最小化后的恢复。
- 可见窗口顺序改用 Apple 明确保证前后顺序的列表；隐藏窗口仅用于保留身份。新宿主和弹窗身份均等待稳定坐标，避免将动画中间帧永久识别为弹窗。
- 切走时清理被中断的拖动和菜单状态；保留文件选择器隐藏、稳定定位与 240ms 出现动画。
- Windows 优先查找桌面版内置 CLI，扩展到多级资源／版本目录、独立安装目录及带本地 Node 的 npm 安装。
- Windows 的空额度回复与未登录响应会明确报错；刷新可重建连接，菜单新增官方 CLI 登录、选择 CLI 和连接诊断入口。
- macOS 菜单新增显示诊断，恢复位置操作会重置宿主识别。

Windows 请退出旧版、解压完整便携目录后运行。先打开并登录 Codex / ChatGPT 桌面版，再刷新；若提示登录不可用，可使用新菜单里的“登录 Codex 账户…”。

验证边界：macOS 覆盖原生多窗口／辅助窗口／文件选择器及动画回归；用户原始间歇性隐藏未确定唯一复现步骤。Windows 的安装布局、真实子进程和原生 WPF 测试使用模拟账户数据，用户 Windows 真机真实账户仍需验收。

Fixes covered macOS visibility recovery paths and improves Windows desktop-only CLI discovery, reconnecting and sign-in recovery. Real-account Windows acceptance remains separate from CI checks.
