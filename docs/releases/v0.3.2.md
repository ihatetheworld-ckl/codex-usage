# Codex Usage v0.3.2

macOS 与 Windows 新增 240 毫秒胶囊展开动画；macOS 同时修复切回 Codex 时的短暂错位。

- 胶囊以固定中心的小点展开为竖向圆角胶囊，数字随后淡入；浮窗坐标与文字字号保持不变。
- 切走、点击、拖动或退出会取消展开；普通定位更新不会重复触发。遵循系统减少动态效果／关闭界面动画的偏好。
- macOS 在台前调度展开主窗口期间保持隐藏，确认窗口坐标稳定后直接显示在最终左下角位置。
- 增加双平台原生界面回归，覆盖动画、中断、定位、拖动、菜单，以及 macOS 文件选择弹窗。

下载包含 macOS Universal 2（Apple Silicon / Intel）、Windows x64 自带运行时的便携包，以及 `SHA256SUMS.txt`。请退出旧版后替换应用或整个 Windows 目录。

macOS 已在本机实际切换中验证；Windows 通过 CI 的原生 WPF 窗口与模拟用量检查，尚未在用户 Windows 设备和真实账户下完成验收。安装包未进行 Apple 公证或 Windows Authenticode 签名。
