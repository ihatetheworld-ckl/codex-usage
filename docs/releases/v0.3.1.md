# Codex Usage v0.3.1

修复 macOS 在打开添加文件／文件夹等系统窗口时，胶囊错误地移动到弹窗上的问题。

- 贴合模式保持绑定主窗口的窗口标识，不再采用最靠前的大窗口。
- 文件选择弹窗打开时暂时隐藏胶囊，取消或关闭后自动恢复到原主窗口左下角。
- 贴合模式使用普通窗口层级，系统弹窗可正常覆盖胶囊；自由悬浮仍保留独立的浮动层级。
- 过滤最小化动画中主窗口的临时缩略图尺寸，避免胶囊短暂贴到缩略图上。
- 新增真实 `NSOpenPanel` 生命周期测试，以及启动时已存在弹窗、窗口移动、最小化恢复和主窗口关闭的回归检查。

macOS 与 Windows 下载包同步提供；Windows 本次仅更新版本号，窗口行为未改动。下载后请退出旧版再替换。安装包仍未进行 Apple 公证或 Windows Authenticode 签名。

Fixes the macOS docked widget following system file pickers instead of the main Codex window. It now keeps a stable main-window identity, hides during host-owned dialogs, and restores its anchor on dismissal. Includes native file-picker regression coverage. Windows behavior is unchanged.
