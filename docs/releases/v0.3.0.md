# Codex Usage v0.3.0

首个公开的 macOS / Windows 同步版本，采用 Apache-2.0 许可证。

- 常驻显示 Codex 5 小时和周剩余用量，每 30 秒查询一次。
- 48 × 84 点小胶囊；贴合模式拖走后松手回到左下角，自由模式保留位置。
- 点击或右键查看详细进度与重置时间，支持仅菜单栏／系统托盘。
- macOS 26+ 使用原生清透玻璃，macOS 13–15 使用磨砂材质。
- Windows 版本采用半透明圆角卡片，提供完整 .NET 运行时的 x64 便携包。

## Downloads

| File | Platform |
| --- | --- |
| `CodexUsage-macOS-universal.zip` | macOS 13+，Apple Silicon 和 Intel |
| `CodexUsage-Windows-x64.zip` | 支持 .NET 10 的 Windows x64，推荐 Windows 11 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验和 |

两款应用都需要本机已登录的 **Codex CLI**，不会附带登录令牌。首次使用可运行 `codex login`。Windows 请在本机 PowerShell 登录，WSL 的登录状态不会自动共享。

## Validation and limitations

发布流程要求 macOS 回归检查和 Windows 用量、子进程及 WPF UI 冒烟检查全部成功，才会同时公开两个下载包。Windows UI 检查使用模拟用量和原生测试窗口，不包含真实账户登录；Windows 首次在真实 Codex 账户下使用仍需用户验收。Intel macOS 切片经过交叉编译，UI 回归检查运行于 Apple Silicon。

安装包未进行 Apple 公证或 Windows Authenticode 签名，系统可能显示开发者验证提示。请从本仓库下载并核对校验和。该项目为独立工具，并非 OpenAI 官方插件。
